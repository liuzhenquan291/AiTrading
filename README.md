# AiTrading · A股主力行为学课程学习笔记

本仓库是一个 A 股交易课程的学习笔记项目，系统整理「众赢财富通」投资顾问 **王旭（为为老师，执业编号 A0870625080015）** 授课的系列课程。课程主线为**主力行为学**：从量价、筹码、竞价、分时、涨停板等盘面语言出发，识别主力资金的吸筹、洗盘、拉升痕迹，并据此制定低吸与打板两套实战策略。

> **郑重提示**：本仓库全部内容为个人学习笔记，不构成任何投资建议。课程中个股仅为案例讲解，过往案例不代表未来收益。投资有风险，入市需谨慎。

## 课程体系

两天课程构成"**选股 → 择时**"的完整闭环：

| | Day01 · 低吸体系 | Day02 · 打板体系 |
| --- | --- | --- |
| 课题 | 《刺客破局·低吸定江山》 | 《竞价抢筹·分时定乾坤》 |
| 解决的问题 | 哪些票有资格涨？底在哪里？何时起爆？ | 涨停后能否连板？哪个二板能打？何时买入？ |
| 策略属性 | 左侧识别结构 + 右侧确认入场（低吸） | 右侧情绪接力（打板/半路） |
| 核心方法 | 涨停基因 → 凹口淘金 → 万人血坑 → 堆量固底 → 势如破竹 | 选板（避坑）→ 验板（换手+封成比+竞价形态）→ 打板（一波流/多波流） |
| 心法 | 别人猜底，我等信号 | 别人猜板，我验质量 |

共同底层逻辑：**真实的底部/强势，都是散户交出来、主力买出来的**；所有方法都是在量价与筹码中寻找"主力真实意图"的证据，而非预测基本面。

## Day01 · 《刺客破局·低吸定江山》

> 完整版：[day01/课程总结.md](day01/课程总结.md) ｜ 思维导图：[day01/思维导图.png](day01/思维导图.png)

**一句话概括**：选股先找有涨停/跳空基因的主力高活跃票，用"ABC 三浪下跌 + C 浪缩量 + 万人血坑 + 堆量固底"识别主力真实底部，最后等"阳线突破斜率 + 成本集中度<30% + 板块共振"的起爆信号再上车——不猜底，只跟主力。

### 四步框架

1. **猎杀第一步·涨停基因**：一年内涨停 ≥ 4 次、跳空 ≥ 4 次 = 主力高活跃票。涨停是主力的身份证，跳空是敲门砖（静音锁筹）。
2. **资金易主·凹口淘金**：完整结构 A跌→B反→C杀→最后一次吸筹→洗盘→主升。硬条件：abc 三段下跌、C 浪跌幅超 A 浪一倍、C 浪量能萎缩至 120 日均量线以下。三浪三洗，洗的不是股价，是人心。
3. **万人血坑·堆量固底**：反弹后回撤 >50% 的挖坑是主力对"底部信念"的定向爆破，期间只观望；洗盘完毕的唯一暗号是坑底**堆量超过 120 日均量线**——没有堆量的万人血坑，不是底，是陷阱。
4. **势如破竹·两大起爆信号**：①明示锋芒——放量大阳线突破万人血坑下跌斜率，阳线越高突破越真；②暗聚强兵——90% 成本集中度 < 30%（主力极度控盘）。总攻 = 突破坑沿高点 + 板块共振。

### 核心口诀

> 真实的底部，是散户割出来的，主力买出来的。
> ABC 三浪三洗，洗的不是股价，是人心！
> 万人血坑千丈深，洗尽散户方见金！
> 没有堆量的万人血坑，不是底，是陷阱！
> 堆量固底出现的那一刻，便是万人血坑见底之时！
> 成本集中度低于 30%，主力极度控盘！
> **别人猜底，我等信号！**

## Day02 · 《竞价抢筹·分时定乾坤》

> 完整版：[day02/课程总结.md](day02/课程总结.md) ｜ 思维导图：[day02/思维导图.png](day02/思维导图.png)

**一句话概括**：二板是"辨"龙头的起点而非终点；绕开弱转强与烂板两类坑，只打"换手充分 + 封成比>30% + 竞价U/V形态"的优质换手二板，分时上一波流接近封板扫板、多波流守不破均线，10 点前上板才是龙头。

### 三步框架

1. **选板·知己知彼**：赵老哥"二板定龙头"应读作"二板**辨**龙头"。两类二板绝对不碰：①**弱转强涨停板**（低开修复/地天板，巨量换手、控盘力弱，宁错过不做错；高位弱转强尤危险）；②**烂板涨停**（多次开板勉强回封，次日大概率断板闷杀）。
2. **验板·一锤定音**：首要标准**必须是换手板**（换手不够板走不久，换手充分连板到手；一字板看似风光实则出货都出不去）；硬件指标**涨停封成比 > 30%**（封单÷成交量，场外抢筹力远大于场内抛压）；最强竞价形态为 **U 字 / V 字吸筹**（可撤单阶段砸恐慌，不可撤单阶段真抢筹）。
3. **打板·一击封喉**：**一波流**——开盘 5 分钟内向上不回踩，接近封板时扫板买入；买不到则做**多波流**（最常见三波：一波测抛压、二波洗浮筹、三波锁仓点火），每次回调**不破分时均线**（承接力强），上板时间**最好 10 点前**，午后板大概率是跟风。

### 核心口诀

> 二板定龙头？——是二板辨龙头！
> 弱转强，宁愿错过，也不做错！
> 换手不够，板走不久；换手充分，连板到手！
> 一字板看似风光，实则出货都出不去！
> 封成比 = 封单 ÷ 成交，大于 30% 板才硬！
> 一波流买在接近封板，多波流守在不破均线！
> **十点前封板是龙头，午后上板是跟风！**
