# 追最热的资金，打最容易的板


今日战法：快速进场潇洒离场


## 第一步:暴力连板看市值
- 市值要求：200亿以内
  * 200亿是主力“拉得动、控的住”的黄金线
  * 主力想做连板，就要用最少的资金获取最大的收益。主力不需要对抗太大的抛压。
  * 热点仍在，主力就很容易利用市场合力拉出连板
  * 热点结束，主力也能很快离场。不像趋势龙，盘子很大，主力需要很长时间才能出货，边拉边出。
  * 举例:
      1. 03.png：合富中国 49.24亿
      2. 04.png: 平潭发展 133.48亿
      3. 05.png: 长飞光纤,  1625.5亿，走的是趋势龙，没办法走连板
      4. 06.png: 大金重工，215.77亿，走的也是趋势龙

2. 情绪加速缺口(加仓型)
出现这种缺口，即使不加仓，也不要减仓。
什么是情绪加速缺口？(32.png，起爆缺口之后的第二个缺口很有可能就是情绪加速缺口)
要看其分时形态，有没有出现高开秒板，一字板。
最暴力的连板，必有情绪加速缺口。
